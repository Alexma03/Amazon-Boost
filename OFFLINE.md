# Preview offline de Amazon Boost

1. Haz doble clic en `ABRIR-WEB-OFFLINE.cmd`.
2. Se abrirá la web en el navegador sin necesitar conexión a Internet.
3. Mantén abierta la ventana titulada `Amazon Boost - Preview offline`.
4. Para cerrar la preview, cierra esa ventana o pulsa `Ctrl+C`.

La navegación, las imágenes, las animaciones, los servicios, las guías, el blog y los casos de éxito funcionan localmente. Los enlaces y funciones externos, como WhatsApp, LinkedIn, Trustpilot, Firebase y la IA generativa, necesitan conexión.
