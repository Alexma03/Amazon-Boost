# Medición mensual de visibilidad en búsqueda con IA

Estado: plantilla preparada el 30 de septiembre de 2026. **Sin línea base real todavía.** No interpretar esta plantilla como prueba de indexación o de menciones.

## Antes de empezar

1. Confirmar que el despliegue aprobado está en `https://amznboost.es/` y que Search Console y Bing Webmaster Tools muestran la propiedad correcta. Guardar la fecha y versión del sitio.
2. Elegir tres superficies: ChatGPT con búsqueda web, Google AI Overviews/AI Mode cuando se muestre, y Bing Copilot con búsqueda. Anotar producto, modalidad y si la sesión está iniciada. No mezclar una respuesta sin búsqueda con una respuesta de búsqueda.
3. Repetir cada consulta dos veces por superficie en español desde España, manteniendo idioma, ubicación y condiciones de sesión. Registrar cada intento por separado. Si una función no aparece, marcar `no_mostrada`; no forzar una respuesta ni contarla como ausencia de marca.
4. No aportar al asistente el nombre de Amazon Boost como contexto previo, documentos privados ni instrucciones que sesguen la respuesta. Usar una sesión limpia o documentar la personalización que no se pueda evitar.

Una **mención** exige que el nombre de la agencia aparezca en la respuesta. Una **cita propia** exige un enlace visible al dominio canónico; una mención sin enlace no cuenta como cita. `Descripción fiel` se valora solo si hay mención: correcta si refleja agencia independiente de Amazon enfocada en marcas y gestión del canal; parcial si omite elementos importantes; incorrecta si atribuye alianzas oficiales, cifras o servicios no acreditados. Conservar la respuesta o captura para poder revisar la clasificación. No guardar datos personales de visitantes.

## Lectura mensual

- **Cobertura de respuesta:** intentos con respuesta de búsqueda / intentos realizados. Informar por plataforma; `no_mostrada` y errores permanecen visibles.
- **Tasa de mención:** respuestas de búsqueda que mencionan Amazon Boost / respuestas de búsqueda válidas. No incluir errores ni `no_mostrada` en este denominador.
- **Tasa de cita propia:** respuestas de búsqueda con enlace a `amznboost.es` / respuestas de búsqueda válidas. Separarla de la tasa de mención.
- **Precisión:** respuestas con mención descritas correctamente / respuestas con mención evaluables. Revisar manualmente las incorrectas antes de sacar conclusiones.
- Registrar URL propia citada, competidores y fuentes externas recurrentes. Comparar con el mes anterior solo a igualdad de consultas, plataforma, país e idioma. Dos ejecuciones siguen siendo una muestra pequeña: describir variación, no significación estadística.
- Añadir a la lectura las impresiones, clics y consultas de Search Console, cobertura de Bing y contactos recibidos, cada uno con su fuente y periodo. El informe Web de Search Console incluye las funciones de IA de Google dentro del rendimiento de búsqueda; no ofrece aquí una atribución de venta a cada respuesta. No equiparar menciones con posiciones orgánicas ni con clientes ganados.

## Control editorial

Si una respuesta cita una página con una afirmación incorrecta, corregir primero la página y conservar la versión anterior para entender el cambio. Si la página es correcta y la respuesta no, registrar el error de la plataforma; no introducir texto artificial, reseñas falsas ni marcado de FAQ para intentar manipularla. La ausencia de cita no justifica crear una URL duplicada.
